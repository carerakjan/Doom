# План покращень Doom-like демо

Робимо по одному пункту на коміт, зверху вниз. Номери рядків вказані за станом коміту `edd678a`.

## A. Баги (виправити першими)

- [x] **A1. Автоповтор клавіш одразу перезапускає рівень після смерті.** `keydown` не перевіряє `e.repeat`. Якщо гравець затиснув Пробіл (стрільбу) і загинув, автоповтор викликає `advanceMenu()`, і екран «ВИ ЗАГИНУЛИ» зникає миттєво. Так само проскакує екран «РІВЕНЬ ПРОЙДЕНО» (~р. 999–1022).
- [x] **A2. Клавіші «залипають» після втрати фокусу.** Немає обробника `blur` / `visibilitychange`: якщо при затиснутій W переключитися на іншу вкладку (Alt+Tab), гравець далі біжить, а `mouseDown` лишається `true`, тож зброя стріляє далі.
- [x] **A3. Після повернення на вкладку музика грає «кашею».** У `music.tick()` (~р. 988) `nextT` не підтягується до `currentTime`. Коли вкладка неактивна, `setInterval` пригальмовується, а після повернення цикл `while` планує всі пропущені кроки в минуле одночасно. Треба `nextT = Math.max(nextT, a.currentTime)`.
- [x] **A4. На босових рівнях вихід відкривається лише після вбивства всіх ворогів на карті.** Ціль показує «ПЕРЕМОЖІТЬ БОСА», але `exitOpen = aliveCount === 0` (~р. 1499). Треба відкривати вихід, коли загинули боси (`bosses.every(b => b.dead)`), або змінити текст цілі.
- [x] **A5. Ворожі снаряди можуть пролітати крізь гравця.** Снаряди `balls` рухаються без підкроків (~р. 1466), а `pballs` гравця з підкроками. Снаряд зі швидкістю 8 при низькому FPS (dt = 0.05) зміщується на 0.4 за кадр, а радіус влучання 0.35. Додати підкроки, як у `updatePballs`.
- [x] **A6. Некромант воскрешає черепи породжувача, і лічильник `spawnN` збивається.** Слот породжувача вже звільнено (`freed`), а череп знову живий. Не воскрешати ворогів з `parent` або скидати `freed`.
- [x] **A7. Звукові ефекти: `exponentialRampToValueAtTime` без `setValueAtTime`.** У `tone()` (~р. 906) пряме присвоєння `gain.value` перед рампою в деяких браузерах дає клацання або ігнорується. Використати `setValueAtTime(vol, now)`.

## B. Геймплей / UX

- [x] **B1. Пауза.** `Esc` / `P`, автопауза при втраті pointer lock, `blur` чи прихованій вкладці, плюс екран «ПАУЗА».
- [x] **B2. Колізія гравця з ворогами.** Зараз гравець проходить крізь монстрів, а вони «залазять» у нього.
- [x] **B3. Підказка, де лишилися вороги** на рівнях «вбийте всіх»: коли живих ≤ 3, показувати їх на мінікарті або стрілкою.
- [x] **B4. Збереження рівня та стану гравця (окрема задача).** Зроблено без експорту/імпорту коду-сейву, його можна додати окремо.
  - **Де зберігати:** у `localStorage`. Для однофайлової гри це найкращий варіант: працює і з `file://`, і на хостингу, дані маленькі (< 1 КБ). IndexedDB тут надмірний, а cookie незручні. Додатково (за бажанням) можна зробити експорт/імпорт сейву рядком-кодом, щоб переносити прогрес між браузерами чи пристроями.
  - **Що зберігати:** `{ v: 1, level, diffIdx, player: { hp, weapon, own, ammo }, muted, best }`. Це той самий `snapshot`, що вже робиться на старті рівня, плюс номер рівня й складність.
  - **Коли зберігати:** на старті кожного рівня, тобто після `snapshot = snap()` у `startLevel`. Рівні детерміновані (генеруються з номера та складності), тож продовження з початку рівня повністю відтворює стан, як і рестарт на `R`. Збереження посеред рівня (вороги, підібрані предмети) не потрібне.
  - **Інтерфейс:** на титульному екрані пункт «ПРОДОВЖИТИ (рівень N, складність)», якщо є сейв, і «НОВА ГРА», яка перезаписує сейв (можливо, з підтвердженням). Після перемоги сейв очищається, рекорд `best` лишається.
  - **Надійність:** усі звернення до `localStorage` обгорнути в `try/catch` (приватний режим, заблоковане сховище); перевіряти поле версії `v` і коректність даних при завантаженні; при помилці гра просто стартує з нуля.
- [x] **B5. Налаштування чутливості миші** (зараз жорстко `0.0025`) і, можливо, інверсія.
- [x] **B6. Авто-перемикання при нестачі патронів** (~р. 1251) не враховує рейкган і руйнівник (індекси 8, 9).
- [x] **B7. Захист від випадкового пропуску екранів:** невелика затримка (~0.5 с) перед тим, як Enter/клік спрацює на екранах «смерть» і «рівень пройдено».
- [ ] **B8. Повноекранний режим.** Клавіша `F` (і кнопка/підказка на титулі) через Fullscreen API: `requestFullscreen()` на контейнері гри, вихід через `F` або `Esc`. Канвас масштабується на весь екран зі збереженням пропорцій 640×400 (`image-rendering: pixelated`). Вихід з повного екрана під час гри ставить її на паузу, як і втрата pointer lock.
- [ ] **B9. Поступове приглушення звуку клавішею `M`.** Замість вкл/вимк гучність іде по колу: 100% → 66% → 33% → 0% (тиша) → знову 100%. Поточний рівень показується тостом (напр. «ЗВУК 66%»). Гучність застосовується до `master` (музика) і до SFX. У сейві (B4) зберігати рівень гучності замість `muted`, з підтримкою старого поля `muted`.
